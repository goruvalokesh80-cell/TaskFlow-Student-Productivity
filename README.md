
# TaskFlow — Student Task & Productivity Management System

TaskFlow is a dark-themed student productivity web application designed
to help students organize assignments, projects, deadlines, and personal tasks.

## Features

- Create, edit, and delete tasks
- Mark tasks as completed or incomplete
- Set task categories and priority levels
- Assign due dates to tasks
- Search tasks by keyword
- Filter tasks by category and priority
- View today's tasks and upcoming deadlines
- Track completed, pending, and overdue tasks
- Monitor overall productivity with a progress indicator
- Automatically save tasks using browser LocalStorage
- Responsive design for desktop and mobile screens

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Browser LocalStorage
- Git and GitHub

## How to Run

1. Clone or download this repository.
2. Open the TaskFlow folder in Visual Studio Code.
3. Open index.html using the Live Server extension,
   or open the file directly in a browser.
4. Create tasks and explore the dashboard.

## Data Storage

TaskFlow stores tasks in the browser's LocalStorage.
Data is specific to the browser and origin being used.
Clearing browser site data may delete saved tasks.

This project does not currently include a backend,
server-side authentication, or a shared database.
